# Support

Use GitHub Issues for reproducible ReMap bugs and focused feature requests. Include the ReMap version or commit, Unity version when relevant, target game, expected behavior, actual behavior, and minimal reproduction steps.

Do not attach proprietary game files, extracted assets, credentials, personal data, or large generated caches. ReMap's issue tracker is not a general support channel for Apex Legends, R5Reloaded, R5Flowstate, Unity, or RSX.

Potential security vulnerabilities must be reported according to [`SECURITY.md`](SECURITY.md), not through a public issue.
