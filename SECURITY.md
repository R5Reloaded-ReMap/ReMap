# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting or security-advisory flow for this repository. Include affected versions, reproduction steps, impact, and any suggested mitigation. Avoid including game files, credentials, personal data, or other sensitive material unless it is strictly necessary to reproduce the issue.

Security reports will be acknowledged and assessed as time permits. No response-time or remediation-time guarantee is provided.

## Supported versions

Until ReMap publishes stable releases, security fixes target the latest development version. After versioned releases begin, this section will list the supported release lines.
